# Photo Jumper · 照片跳跳乐

上传一张照片，AI 自动识别画面里的物体，把它们变成 3D 跳跃关卡的平台。控制小人在平台之间跳跃，到达顶部的星星。

## 玩法

1. 上传任意一张照片（人物、风景、室内、物体均可）
2. AI（COCO-SSD 模型）自动识别照片中的物体
3. 每个检测到的物体变成一个 3D 平台，按位置排列
4. 控制蓝色小人跳跃攀登，目标是顶部的金色星星

## 操作

| 按键 | 功能 |
|------|------|
| W A S D | 移动 |
| 方向键 | 移动 |
| Space | 跳跃 |

## 技术栈

- **Three.js** — 3D 渲染、光照、阴影
- **TensorFlow.js + COCO-SSD** — 浏览器端目标检测（80 类物体）
- **原生 JS** — 物理引擎（重力、AABB 碰撞、跳跃力学）
- **CSS3** — 玻璃态 UI、动画
- 零后端、零构建工具，纯静态部署

## 工作原理

```
照片 → COCO-SSD 检测物体 → 生成 3D 平台 → 按位置排列 → 跳跃关卡
```

1. 用户上传照片后，COCO-SSD 模型在浏览器中推理，输出检测到的物体类别、位置和置信度
2. 每个检测框映射为一个 3D 平台：照片 X→世界 X，照片 Y→世界 Z，高度按检测顺序递增
3. 平台尺寸由检测框大小决定，颜色按物体类别分配
4. 每个平台上方生成对应物体的简易 3D 模型作为装饰
5. 原始照片以半透明纹理铺在地面，平台从照片对应位置升起
6. 顶部平台放置星星，底部放置可控角色
